## Why

Every time I built an app, I kept reaching for the same thing: a way to see what was actually happening. I tried a few existing tools but they were either built for enterprises with dashboards I didn't need, or they were too simple to be useful. I wanted something lightweight that I could drop into a project in five minutes and get real answers from.

Vanta is that tool. You send it events, and it shows you everything in realtime. No setup wizard, no config files, no waiting for data to process.

{image:1}

## Features

- Event analytics with realtime filtering and search
- User profiles showing activity history and retention
- Custom dashboards for tracking the metrics that matter to you
- Performance and uptime monitoring
- Ingestion API that works with any language or platform

{image:2}

## Tech Stack

Built with **React** and **TypeScript**. The backend handles a realtime event pipeline that ingests, indexes, and serves data with low latency. Everything runs on Vanta's own infrastructure.

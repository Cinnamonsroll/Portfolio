## Why

sve.one was a concept project. It was a platform where you could write HTML and CSS and have it hosted instantly at `yoursite.sve.one`. Think of it as a playground for simple static sites, no setup required. The name "sve" reads like "71", hence the logo.

It was built and archived in 2022 as a proof of concept with no intention of scaling.

{image:1}

## Features

- Write HTML and CSS in the browser editor
- Instant hosting on a `yoursite.sve.one` subdomain
- Dashboard to manage your sites
- Discord-based authentication
- Public site directory and search

{image:2}

## Tech Stack

Built with **Express** + **EJS** templating, **Bootstrap 4** (Argon theme), **MongoDB** via Mongoose, and **Passport** for Discord OAuth.
